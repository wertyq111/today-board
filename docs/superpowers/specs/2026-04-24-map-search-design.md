# 地图地址搜索设计

## 1. 结论

| 项目 | 设计 |
| --- | --- |
| 功能目标 | 配置“家”和“公司”时，可以用真实地点搜索选中地址 |
| 进入位置 | 首次配置页和后续设置里的基础地址修改入口 |
| 技术方向 | 高德 Web 服务 API 地点搜索 + 设置页本机 Key 配置 |
| 数据原则 | 不造地点数据；未配置真实服务时明确显示“地图搜索未配置” |
| 第一版边界 | 不做完整地图页、不做路线规划、不做导航、不做后端 |

## 2. 做与不做

| 做 | 不做 |
| --- | --- |
| 输入关键词后调用真实地点搜索接口 | 不内置离线地图数据 |
| 展示真实返回的地点名、详细地址、经纬度 | 不用假数据填充结果 |
| 用户点选后写入本地配置 | 不自动纠偏用户输入 |
| 密钥只保存在本机应用存储 | 不把 Key 写入源码、资源或仓库文件 |
| 没有 Key 时保留手动输入，并关闭搜索按钮 | 不把手动输入伪装成地图选点 |

## 3. 用户流程

| 步骤 | 行为 |
| --- | --- |
| 1 | 用户进入首次配置页，看到“家”和“公司”两个地址区块 |
| 2 | 用户可直接手动输入，也可点“搜索地图地点” |
| 3 | 搜索面板要求输入至少 2 个字，再允许调用搜索 |
| 4 | 搜索结果列表展示地点名、详细地址和来源标识 |
| 5 | 用户点选某个结果后，地址区块显示“已选地图地点” |
| 6 | 用户点“完成首次配置”或“保存修改”后，选择结果写入本地存储 |

## 4. 数据模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `source` | `'manual' \| 'place_search'` | 地址来源 |
| `provider` | `string` | 地点服务提供方，第一版为 `amap` |
| `placeId` | `string` | 服务方返回的地点 ID |
| `name` | `string` | 地点名 |
| `address` | `string` | 详细地址 |
| `latitude` | `number` | 纬度；地图选点必须有 |
| `longitude` | `number` | 经度；地图选点必须有 |
| `selectedAt` | `number` | 选择时间戳 |

本地存储保留现有 `setup.homeAddress` 和 `setup.officeAddress` 作为展示文案，同时新增：

| Key | 说明 |
| --- | --- |
| `setup.homeAddressSelectionJson` | 家的地图选点详情 |
| `setup.officeAddressSelectionJson` | 公司的地图选点详情 |

## 5. 模块拆分

| 模块 | 职责 |
| --- | --- |
| `AddressSearchPanel` | 只负责输入关键词、触发搜索、展示结果、发出选中事件 |
| `MapSearchService` | 校验配置、调用 provider、统一返回结果格式 |
| `MapSearchService` | 第一版直接对接高德 Web 服务 API；等出现第二个服务商再拆 provider |
| `SetupStore` | 保存手动地址和地图选点详情 |
| `SetupPage` | 组织家/公司地址区块，不直接写接口请求逻辑 |

## 6. 配置与密钥

| 项目 | 设计 |
| --- | --- |
| Key 存放 | 设置页输入后写入本机 `AppStorage/PersistentStorage` |
| 工程文件 | 不把 Key 写入 `project-info.json`、源码或资源文件 |
| 未配置 Key | 搜索入口显示不可用原因，不发请求 |
| 网络权限 | 实施时补 HarmonyOS 网络访问声明 |
| 定位权限 | 第一版搜索不强制请求定位权限，避免为了搜地址多要权限 |

## 7. 错误处理

| 场景 | 处理 |
| --- | --- |
| 未配置服务或 Key | 显示“地图搜索未配置”，搜索按钮不可点 |
| 请求失败 | 显示接口错误，不返回空假结果 |
| 无搜索结果 | 显示“没有找到地点”，允许用户改关键词 |
| 结果缺少经纬度 | 不允许作为地图地点保存 |
| 用户只手动输入 | 保存为 `manual` 来源，不写经纬度 |

## 8. 验证清单

| 验证项 | 通过标准 |
| --- | --- |
| 无 Key 状态 | 页面不崩溃，搜索入口明确不可用 |
| 有 Key 搜索 | 真实接口返回地点列表，不出现 mock 数据 |
| 选择地点 | 家/公司显示选中的地点名和详细地址 |
| 保存重开 | 退出再进入后仍能看到已选地点 |
| 手动输入 | 不走地图搜索，也能完成当前配置流 |
| 构建运行 | DevEco `Run entry` 能启动，入口不报错 |

## 9. 实施顺序

| 顺序 | 内容 |
| --- | --- |
| 1 | 补 `AddressSelection` 数据结构和 `SetupStore` 存取 |
| 2 | 补 `MapSearchService`，通过高德 Web 服务 API 查询真实 POI |
| 3 | 在设置页补本机 Key 和城市配置 |
| 4 | 在 `SetupPage` 接入地址搜索面板 |
| 5 | 补无 Key、有 Key、无结果、缺经纬度的验证 |

## 10. 未决项

| 项目 | 需要确认 |
| --- | --- |
| 真实 Key | 实测真实搜索前需要在设置页填入可用高德 Web 服务 Key |
| 城市范围 | 第一版可在设置页填城市中文或 adcode；默认全国搜索 |
