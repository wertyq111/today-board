# 今日出门板票据式 UI 重做

## 方向

视觉基调：清爽通勤票据。米白纸面、墨绿标题区、橙色提醒，像早晨出门前扫一眼的车票或登机牌。

目标不是堆卡片，而是让用户 5 秒内看懂三件事：

| 优先级 | 信息 |
| --- | --- |
| 1 | 几点前出门 |
| 2 | 走哪种通勤方式 |
| 3 | 今天还有哪些风险和随身提醒 |

## 改动范围

| 文件 | 改动 |
| --- | --- |
| `AppTheme.ets` | 统一票据风格颜色、字号、圆角和间距 |
| `Index.ets` | 首页改成大通勤票，减少卡片堆叠 |
| `SetupPage.ets` | 首次配置改成分步骤表单 |
| `SettingsPage.ets` | 设置页改成分组列表 |
| `ChecklistPage.ets` | 清单页改成纸条列表 |
| `CommuteOptionsPage.ets` | 通勤方案页改成横向数据条 |
| `TodayBoardCard.ets` | 服务卡片改成迷你通勤票 |

## 约束

| 约束 | 处理 |
| --- | --- |
| 不造数据 | 所有内容仍来自本地配置、日历、天气状态和决策引擎 |
| 不引入后端 | 只改 ArkUI 布局和主题 |
| 不隐藏失败 | 天气、日历、地图状态仍直接显示 |
| 不写真实 Key | 地图 Key 仍只保存在已忽略本机文件或应用本机存储 |
