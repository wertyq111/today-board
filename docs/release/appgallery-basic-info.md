## 一句话简介

早晨打开一次，快速看今天的天气、日程和出门清单。

## 应用介绍

天气看门板是一款离线优先的出门提醒工具。应用会在本机展示今日天气、系统日历日程和出门清单，帮助用户在出门前快速确认是否需要带伞、带水杯、带工牌等物品。清单数据保存在本机，不需要登录账号，也不依赖后端服务。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 日历权限 | 读取今天第一条后续日程，并在看板中显示日程状态 |
| 定位权限 | 获取当前位置，用于刷新本地天气 |
| 网络权限 | 请求天气接口并获取真实天气结果 |

## 隐私摘要

应用不提供账号系统，不上传用户清单，不上传日历内容到自有服务器。天气刷新需要使用当前位置请求天气服务；日历只在设备本机读取并展示当天日程状态。
