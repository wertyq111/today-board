# 今日出门板测试 PRD

## 1. 产品目标

| 项目 | 内容 |
| --- | --- |
| 产品方向 | 无后端、无地图、首版不做实时天气的本地出门提醒工具 |
| 核心用户 | 早晨出门前容易漏带东西的上班通勤人群 |
| 核心价值 | 打开首页 5 秒内知道今天还差什么、哪些已确认、哪些是场景提醒 |
| 数据边界 | 所有清单、规则、确认状态保存在本机 |
| 不做范围 | 地图搜索、路线规划、实时天气、后端同步、账号登录 |

## 2. 页面清单

| 页面 | 主要目标 | 验收重点 |
| --- | --- | --- |
| 首次配置 | 配置常带物品、提醒偏好、出门提醒时间、桌面卡片开关 | 完成后能进入首页；未完成时不展示假数据 |
| 今日首页 | 展示今日确认区、场景提醒、出门清单、已带/未带状态 | 5 秒内能看懂未确认项；无地图和实时天气承诺 |
| 清单编辑 | 新增、编辑、启用、停用出门物品 | 保存后首页同步更新 |
| 提醒规则 | 管理雨具、遮阳、固定项、出门前提醒等规则 | 每条提醒都能解释来源 |
| 我的/设置 | 管理本地配置、日历权限、桌面卡片、天气未来入口状态 | 不再出现地图 Key、家/公司搜索、路线配置 |
| 桌面服务卡片 | 展示最关键的未确认项和今日场景提醒 | 信息短、准、稳定，点击进入首页 |

## 3. 核心流程

| 流程 | 步骤 | 通过标准 |
| --- | --- | --- |
| 首次配置闭环 | 打开 App → 选择常带物品 → 设置提醒偏好 → 保存 | 首页展示用户真实配置项 |
| 清单编辑闭环 | 进入清单编辑 → 新增物品 → 保存 → 回首页 | 新物品出现在首页清单中 |
| 今日确认闭环 | 首页点击物品确认 → 状态变为已带 → 桌面卡片刷新 | 已确认项不再作为待办重点展示 |
| 场景提醒闭环 | 进入提醒规则 → 打开强日晒标签 → 回首页 | 首页出现遮阳/防晒相关提醒 |
| 设置闭环 | 进入我的/设置 → 修改桌面卡片开关 | 服务卡片展示逻辑与设置一致 |

## 4. 字段定义

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| itemName | string | 物品名称 | 工牌、水杯、雨伞 |
| category | enum | 物品分类 | fixed、weather、commute、custom |
| enabled | boolean | 是否启用 | true |
| confirmedToday | boolean | 今日是否已确认 | false |
| triggerType | enum | 触发方式 | always、weekday、rain_tag、sun_tag、manual |
| importance | enum | 重要程度 | normal、important |
| reminderTime | string | 出门前提醒时间 | 20 分钟前 |
| widgetEnabled | boolean | 是否显示桌面卡片 | true |

## 5. 提醒规则

| 规则 | 触发条件 | 展示结果 |
| --- | --- | --- |
| 固定项提醒 | 物品 `enabled=true` 且 `triggerType=always` | 每天进入首页清单 |
| 工作日提醒 | 当前日期为工作日且 `triggerType=weekday` | 工作日进入首页清单 |
| 雨具提醒 | 用户手动打开雨天标签 | 雨伞等雨具类物品进入今日提醒 |
| 遮阳提醒 | 用户手动打开强日晒标签 | 防晒、帽子、墨镜等物品进入今日提醒 |
| 出门前提醒 | 到达用户设置的提醒时间 | 推送或卡片突出未确认项 |
| 已确认过滤 | `confirmedToday=true` | 首页降低权重，桌面卡片不作为未确认项展示 |

## 6. 空状态

| 场景 | 页面表现 | 验收标准 |
| --- | --- | --- |
| 未配置任何物品 | 首页提示先添加出门清单 | 不展示默认假清单 |
| 未打开任何场景标签 | 场景提醒显示“今天未选择场景标签” | 不自动猜测天气 |
| 桌面卡片关闭 | 设置页显示关闭状态 | 桌面卡片不应继续展示新提醒 |
| 日历未授权 | 设置页显示未授权 | 首页仍能使用清单，不阻断核心功能 |
| 天气未接入 | 设置页显示首版未启用 | 首页不显示温度、降雨概率、体感等实时天气字段 |

## 7. 错误状态

| 场景 | 处理方式 | 不允许的行为 |
| --- | --- | --- |
| 本地保存失败 | 直接提示保存失败，保留用户输入 | 静默吞错 |
| 本地读取失败 | 显示读取失败并引导重新配置 | 填充假清单 |
| 日历权限拒绝 | 明确显示日历未授权 | 反复弹权限请求 |
| 天气能力不可用 | 显示首版不接入实时天气 | 显示假温度或假降雨 |
| 地图能力不存在 | 页面不出现地图入口 | 显示地图配置残留 |

## 8. 测试用例

| 编号 | 用例 | 操作 | 预期 |
| --- | --- | --- | --- |
| T01 | 首次配置保存 | 选择工牌、水杯、耳机并保存 | 首页显示这 3 个物品 |
| T02 | 新增自定义物品 | 在清单编辑新增“门禁卡” | 首页和清单页均出现“门禁卡” |
| T03 | 停用物品 | 停用“耳机” | 首页不再展示耳机 |
| T04 | 今日确认 | 首页确认“水杯” | 水杯状态变为已带 |
| T05 | 雨天标签 | 打开雨天标签 | 雨伞进入今日提醒 |
| T06 | 强日晒标签 | 打开强日晒标签 | 防晒/帽子进入今日提醒 |
| T07 | 桌面卡片 | 开启桌面卡片 | 卡片展示未确认项前三个 |
| T08 | 无清单 | 清空所有物品 | 首页显示空状态，不展示默认假数据 |
| T09 | 无天气 | 保持实时天气未启用 | 首页不显示温度和降雨概率 |
| T10 | 无地图 | 全页面检查 | 不出现地图、路线、导航、地图 Key |

## 9. 验收标准

| 类型 | 标准 |
| --- | --- |
| 产品验收 | 无后端、无地图、无实时天气依赖，核心闭环可用 |
| 视觉验收 | 主视觉统一为晨间备忘板，首页能快速区分已确认和未确认 |
| 数据验收 | 只展示用户配置和本机状态，不造清单、不造天气 |
| 流程验收 | 首次配置、清单编辑、规则提醒、桌面卡片均形成闭环 |
| 回归验收 | 删除地图用户路径后，不残留地图 Key、家/公司搜索、路线小地图 |

## 10. 实现备注

| 项 | 备注 |
| --- | --- |
| 清单数据 | 后续建议从逗号字符串升级为结构化本地数据 |
| 天气服务 | `WeatherService` 只保留未来状态说明或删除入口，不参与核心提醒 |
| 地图服务 | `MapSearchService` 和相关配置从用户路径移除 |
| 服务卡片 | 复用首页同一份本机清单状态，避免两套规则 |
