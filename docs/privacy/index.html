天气看门板是一个离线优先的 HarmonyOS NEXT 应用，用来在本机集中查看天气、日程和出门清单。 我们尊重并保护你的个人信息。本政策用于说明我们会收集什么、为什么收集、如何使用，以及你可以如何管理自己的信息。

2. 适用范围

本政策适用于天气看门板应用内提供的功能和服务，包括天气刷新、日历读取、出门清单、本地提醒判断和桌面卡片展示。 如果本应用后续新增需要收集或处理个人信息的功能，我们会在功能上线前更新本政策。

3. 信息收集与使用

天气看门板不提供账号系统，不要求注册登录，也不提供聊天、评论、发布内容、支付和广告功能。

3.1 我们会收集的信息

信息类型 用途
日历信息 在你授权后读取系统日历中今天的后续日程，用于首页和提醒页展示日程状态。
位置信息 在你授权后获取当前位置，用于定位当前城市、行政区编码，并刷新真实天气。
出门清单和本地设置 保存你勾选的清单、自定义清单内容和本地看板设置，便于再次打开应用时继续使用。
地点搜索关键词 当你在首次配置页主动使用地点搜索时，会把你输入的地点关键词发送给高德开放平台，用于返回真实地点候选结果。

3.2 权限说明

权限 用途
日历权限 读取今天的后续日程，并展示在天气看板和提醒信息里。
定位权限 获取当前位置，用于天气刷新和当前位置名称展示。
网络权限 访问高德开放平台天气、地理编码和地点搜索接口，返回真实天气和地点结果。

3.3 我们如何使用这些信息

  • 日历信息只用于本机展示当天日程状态，不会上传到开发者自有服务器。
  • 位置信息只用于本次或最近一次天气刷新，不会用于广告、画像或行为分析。
  • 出门清单和本地设置只保存在设备本地，用于维持你的使用状态。
  • 如果你不授权日历或定位，对应功能会直接不可用或显示缺失状态，不会用虚构数据代替。

4. 信息共享、转让和公开披露

4.1 不会共享给自有服务器

天气看门板没有自有后端服务。我们不会把你的日历内容、清单内容或设备上的本地设置上传到开发者自有服务器。

4.2 第三方服务说明

为了提供真实天气、地理位置解析和地点搜索功能，应用会在你主动触发相关功能并授权后，请求高德开放平台接口。 发送的信息可能包括经纬度、行政区编码和你输入的地点关键词。该部分信息由高德开放平台按照其自身规则处理。

第三方服务 使用场景
高德开放平台 天气查询、逆地理编码、地点搜索

4.3 法定情形

在法律法规要求、司法机关或行政机关依法提出要求的情况下，我们可能依法配合提供相关信息。

5. 信息存储与保护

  • 出门清单、本地设置、天气摘要缓存和日历状态摘要默认保存在你的设备本地。
  • 我们采取应用内最小化原则，只保留实现当前功能所需的信息。
  • 由于互联网环境并非绝对安全，请你妥善保管自己的设备和系统权限设置。

6. 你的权利

你可以通过以下方式管理自己的个人信息和授权：

  • 在系统设置中关闭日历权限或定位权限。关闭后，对应功能将停止工作。
  • 在应用内修改或清空你的出门清单和本地设置。
  • 卸载应用后，保存在应用沙箱内的数据会随应用一起删除，但是否完全删除仍以系统行为为准。
  • 如果你对本政策或个人信息处理有疑问，可以通过本页公布的联系邮箱与我们联系。

7. 未成年人说明

本应用不是专门面向未成年人设计的产品。如你是未成年人，请在监护人指导下阅读并决定是否使用本应用。
